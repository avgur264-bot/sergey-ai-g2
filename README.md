# Sergey AI — голосовой ассистент для Even Realities G2

Плагин Even Hub: тап по дужке → вопрос голосом → короткий ответ на HUD.
Свой STT, своя модель, свои инструменты. Ключи живут на устройстве.

```
G2 (микрофон + тачпад)
  ↓ BLE
Even App → WebView с этим плагином
  ↓ WebSocket           ↓ HTTPS
Soniox (распознавание)  LLM (ответ + вызов инструментов)
  ↓
HUD 576×288, монохром
```

## Требования

- Node.js 20 LTS или новее
- Even Realities App с включённым Developer Mode
  (Even Hub → принудительно закрыть приложение → открыть заново → раздел разработчика справа вверху)
- Ключ [Soniox](https://soniox.com) — распознавание речи
- Ключ Anthropic или OpenAI — ответы

## Установка

```bash
npm install
npm run dev          # http://localhost:5173
```

Откройте `/settings.html`, введите ключи. Они пишутся в KVS устройства
(в браузере — в localStorage) и не уходят никуда, кроме самих провайдеров.

### Отладка в браузере

Главная страница рисует превью HUD в реальной пропорции 2:1.
Жесты — с клавиатуры:

| Клавиша | Жест |
|---|---|
| `Enter` | тап |
| `D` | двойной тап |
| `↑` `↓` | листать страницы |

Микрофона в браузере нет — для голоса нужен симулятор или очки.

### Симулятор

```bash
npm run sim
```

### Сайдлоад на очки

```bash
npm run dev
npx evenhub qr       # QR ведёт на локальный сервер
```

Телефон и ноутбук — в одной сети **без изоляции клиентов** на точке доступа.
Не загружается — почти всегда дело в файрволе или AP isolation.

⚠️ **Через сайдлоад не работают:** геолокация (`PERMISSION_DENIED`) и жизнь
приложения в фоне. Это не баги — так устроен режим. Проверять только на `.ehpk`.

### Сборка пакета

```bash
npm run build
npm run pack         # → sergey-ai.ehpk
```

Дальше — Private Testing в кабинете разработчика. Ревью для личной сборки не нужно.

## Как добавить инструмент

```ts
export const noteTool: ToolSpec = {
  name: 'note_add',
  description: 'Сохранить заметку.',
  kind: 'write',            // write → спросит подтверждение на HUD
  transport: 'direct',      // direct | proxy | local
  label: 'ЗАМЕТКА',         // покажется на HUD, пока идёт вызов
  schema: {
    type: 'object',
    properties: { text: { type: 'string' } },
    required: ['text'],
  },
  confirm: (a) => `Записать:\n${a.text}`,
  async run(args, ctx) {
    await fetch('...', { signal: ctx.signal, /* ... */ });
    return { data: 'ok', direct: 'ЗАПИСАНО' };
  },
};
```

Зарегистрировать в `defaultTools`, домен добавить в `whitelist` манифеста.

**`kind: 'write'` для всего, что меняет мир.** STT путает имена, и «отправь Ане»
легко превращается в «отправь Ване». Подтверждение — не формальность.

**`transport: 'proxy'`** — для OAuth-сервисов (Google Calendar, Gmail) и всего,
что не отдаёт CORS-заголовки. Из WebView их звать нельзя, нужен свой воркер.

## Прокси (нужен не всем)

Разверните `worker/`, если хотите календарь, или если телефон
в сети региона, откуда провайдер не отвечает:

```bash
npm i -g wrangler
cd worker
wrangler secret put PROXY_TOKEN          # длинная случайная строка
wrangler secret put ANTHROPIC_API_KEY
wrangler secret put GOOGLE_CLIENT_ID
wrangler secret put GOOGLE_CLIENT_SECRET
wrangler secret put GOOGLE_REFRESH_TOKEN
wrangler deploy
```

Refresh-токен Google берётся один раз в
[OAuth Playground](https://developers.google.com/oauthplayground),
scope `https://www.googleapis.com/auth/calendar.events`.

Дальше в настройках плагина: адрес API = URL воркера,
ключ модели = значение `PROXY_TOKEN`. Настоящий ключ остаётся на сервере.

## Скорость

Три вещи, которые убирают ощущение медленности:

1. **Fast-path** (`agent/router.ts`) — «таймер десять минут», «запомни …», «погода»
   исполняются локально, модель не вызывается вообще.
2. **Стриминг** — первое предложение появляется на HUD до конца генерации,
   через `textContainerUpgrade` (без мигания экрана).
3. **Короткий вывод** — `max_tokens: 200`, детали уходят на вторую страницу.

Плюс кэширование промпта: системный промпт и схемы инструментов не меняются
между запросами и составляют почти весь вход. Кэш режет счёт примерно втрое.

## Тесты

```bash
npm test
```

Покрыты места, где ломается тихо: пагинация (обрезка текста на очках),
fast-path (регресс = вернувшаяся медленность), переходы автомата.

Один настоящий баг тесты уже поймали: `\b` в JavaScript определяется
через ASCII-`\w`, поэтому после кириллицы границы слова нет и
`/погода\b/` не срабатывал вовсе.

## Известные ограничения

- Русского нет в `supported_languages` манифеста — там только
  `en, de, fr, es, it, zh, ja, ko`. На язык ответов это не влияет.
- Размер шрифта на HUD программно не меняется. `CHARS_PER_PAGE`
  в `hud/renderer.ts` подобран на глаз — поправьте после первого прогона на очках.
- Vision не реализован: у очков нет камеры, а камера телефона требует
  отдельной ветки и проверки на `.ehpk`.
- Wake-word невозможен: микрофон включается только когда плагин открыт.
